## MODIFIED Requirements

### Requirement: Заметки агента отделены от заметок человека

Запись SHALL иметь поле `agentNotes` — ленту вида `[{ at, text }]`, куда пишет агент.

Агент MUST NOT править поле `notes`, которое пишет человек. Текст пользователя
остаётся неприкосновенным.

Результат делегированной задачи SHALL дописываться в `agentNotes` одной записью, не затирая
прежние. Формат записи: для результата «Результат агента» и текст черновика, для уточнения
«Вопрос агента:» и вопрос, для сбоя «Агент не справился:» и причина одной строкой. Записи
`agentNotes` без дополнительной структуры и записи без самого поля SHALL читаться как прежде.

#### Scenario: Агент дописывает контекст

- **WHEN** агент вызывает `task_comment` для существующей задачи
- **THEN** запись появляется в `agentNotes`
- **AND** поле `notes` не изменяется

#### Scenario: Обе ленты видны в карточке

- **WHEN** у входящего есть и заметка агента, и заметка человека
- **THEN** интерфейс показывает их раздельно, различимо по происхождению

#### Scenario: Результат делегирования дописывается

- **WHEN** у задачи уже есть заметки агента, а делегированная задача получает результат
- **THEN** в `agentNotes` добавляется новая запись «Результат агента» с текстом черновика
- **AND** прежние записи и поле `notes` не изменены

#### Scenario: Вопрос и сбой

- **WHEN** агент возвращает `needs_info` или `failed`
- **THEN** в `agentNotes` добавляется запись «Вопрос агента: …» или «Агент не справился: …» соответственно

#### Scenario: Запись без agentNotes

- **WHEN** загружается запись без поля `agentNotes`
- **THEN** она читается и отображается как раньше
